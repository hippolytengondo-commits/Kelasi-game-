# Kelas Game

Jeu d'aventure éducatif (HTML/CSS/JS, sans dépendance) : village défilant, école LEXARIS ACADÉMIE, quêtes de calcul, français, géographie et histoire de la RDC.

- **Quêtes** : Mama Lola → Professeure Ilunga → Junior → Directeur Mavungu (étoiles selon les erreurs).
- **Économie** : pièces, XP et niveaux ; mini-jeu de cueillette au manguier ; vente de mangues et achats chez Maman Béa.
- **Maison** : 6 objets à acheter qui apparaissent dans la maison ; révisions rejouables avec questions aléatoires.
- **Sauvegarde** automatique (localStorage), sons WebAudio, commandes tactiles et clavier (← → / E / M).

Lancement : ouvrir `index.html`. Déploiement : site statique (Netlify, `netlify.toml` inclus).
