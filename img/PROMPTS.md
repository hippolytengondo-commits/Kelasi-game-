# Images du jeu (générées, style photo réaliste, RDC / Kinshasa)

- `portraits/<id>.jpg` : lola, ilunga, junior, mavungu, bea, mama (affichés dans les dialogues).
- `tex/` : grass, dirt, brick (remplacent les textures dessinées du monde 3D).
- `scenes/` : kinshasa (fond de l'écran de départ), marche, fleuve (affiches de la classe).

Toute nouvelle image doit être listée dans `manifest.json` pour être chargée.
